System Architecture Flow Diagram
System Architecture Layer Stack
Container Layer .MUSO
Packages ciphertext payload, 12-byte IV (nonce), PBKDF2 salt, file metadata (filename, byte size, MIME type), and expiration control fields for structured serialization and later loading.
Integrity Layer SHA-256
Calculates SHA-256 hashes pre-encryption and post-decryption; exposes comparison fields to verify recovered data integrity and detect modifications.
Key Utility Layer AES / RSA
Provides symmetric-key generation (AES-256) and RSA key-pair generation (2048/4096-bit) with public/private key export controls in standard PEM formats.
Transfer / Demo Layer P2P / QR
Offers transfer-link and QR controls plus a peer-to-peer demo interface described as using BroadcastChannel and ephemeral ECDH.
Audit / Reporting Layer JSON / CSV
Displays cryptographic event information (timestamps, algorithms, digests, status) and provides JSON/CSV export controls.
Security note: AES-GCM provides confidentiality and authentication when used correctly with a unique nonce and a protected key. A SHA-256 hash comparison is useful for detecting differences when the expected hash is trustworthy, but a plain hash by itself is not a digital signature or proof of sender identity.
